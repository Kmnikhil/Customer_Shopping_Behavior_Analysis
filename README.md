# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using transactional retail data. The objective is to uncover customer purchasing patterns, product preferences, spending behavior, and subscription trends to support data-driven business decisions.

The project follows a complete data analytics workflow:

1. Data Preparation and Cleaning using Python
2. Data Storage and Analysis using MySQL
3. Interactive Dashboard Development using Power BI

---

## Dataset Information

The dataset contains customer shopping transactions with information related to:

* Customer demographics

  * Age
  * Gender
  * Location
  * Subscription Status

* Purchase details

  * Item Purchased
  * Category
  * Purchase Amount
  * Season
  * Size
  * Color

* Shopping behavior

  * Discount Applied
  * Promo Code Used
  * Previous Purchases
  * Frequency of Purchases
  * Review Rating
  * Shipping Type

### Dataset Summary

* Total Records: 3,900
* Total Features: 18
* Missing Values: Review Rating column contained missing values

## Data Preparation Using Python

The raw dataset was cleaned and transformed before analysis.

### Data Cleaning

* Loaded dataset using Pandas.
* Performed exploratory data analysis.
* Checked data types and summary statistics.
* Identified missing values.

### Missing Value Handling

The missing values in the Review Rating column were imputed using the median rating of each product category to maintain data consistency.

### Feature Engineering

Created additional features to improve analysis:

* Age Group Classification
* Purchase Frequency Metrics

### Data Consistency Checks

* Verified relationships between Discount Applied and Promo Code Used.
* Removed redundant columns where necessary.
* Standardized column names for readability.

### Database Integration

After cleaning, the transformed dataset was imported into MySQL for further business analysis.

---

## Business Analysis Using MySQL

Several KPI and business-focused SQL analyses were performed.

### Key Business Questions

1. Revenue generated by Gender
2. High-spending customers who used discounts
3. Top-rated products based on customer reviews
4. Comparison of Standard vs Express shipping purchases
5. Subscribers vs Non-Subscribers spending behavior
6. Products most dependent on discounts
7. Customer segmentation based on purchase history
8. Top 3 purchased products within each category
9. Relationship between repeat purchases and subscriptions
10. Revenue contribution by age group

## Key Insights

* Customer spending patterns vary across age groups.
* Subscription status influences purchasing behavior.
* Certain products rely heavily on discount-driven sales.
* Loyal customers contribute significantly to overall revenue.
* Top-rated products can be leveraged for targeted marketing campaigns.
* Shipping preferences impact average purchase value.
